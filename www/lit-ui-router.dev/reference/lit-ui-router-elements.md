# Custom elements

The custom elements `lit-ui-router` defines, as its
[Custom Elements Manifest](https://custom-elements-manifest.open-wc.org/)
records them: each element's properties, attributes, methods, events, slots and
CSS parts. The manifest ships in the package as
`lit-ui-router/custom-elements.json`, the file editors and documentation tools
read.

Each element's class has a page in the [API reference](/reference/lit-ui-router/)
with its full type signatures, and
[Entry Points](/packages/lit-ui-router#entry-points) on the package page covers
the imports that define the elements.
