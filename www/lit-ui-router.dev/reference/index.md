# API

The generated API reference for each package, grouped by role. Each one lists
the package's exports with their type signatures; its package page covers
installation and usage, and the [`lit-ui-router`](/packages/lit-ui-router)
page covers the entry points, link directives and active-link markup.

<!-- reference-index -->

## Custom elements

[Custom elements](/reference/lit-ui-router/elements) lists `<ui-router>` and
`<ui-view>` with the properties, attributes, events and slots that
`lit-ui-router/custom-elements.json` records.

## Attribute-part forms

`srefHref`, `srefActiveClass` and `srefAriaCurrent` are covered under
[Attribute-part forms](/packages/lit-ui-router#attribute-part-forms) on the
`lit-ui-router` package page.
