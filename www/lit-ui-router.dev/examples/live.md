# Live examples

The examples no tutorial or guide page embeds yet, each running live. The
Preview tab runs the built app this site serves; the Edit in StackBlitz tab
boots an editable workspace installed from the published npm packages. The
[examples index](/examples/) lists every example and the page that embeds it.

The Features Tour also runs in the home page itself, without a frame, on a
fragment it shares with the page's anchors:
<a href="/#see-it-run/views">open it on its Views card</a>.
