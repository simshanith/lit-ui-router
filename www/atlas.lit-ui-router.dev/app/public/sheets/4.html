GENERAL NOTES

Method — four provenances, kept apart. This repo's own gates — the core range its eleven router packages share and the four ranges declared on lit-ui-router itself — are read from www/atlas.lit-ui-router.dev/data/census-couplings.json (origin/main @ 08ee3c27); the upstream limbs' gates are read from their manifests by hand. Versions and last-publish dates are not typed on this sheet: every one is read by name from www/atlas.lit-ui-router.dev/data/census-npm.json (npm view, npm registry read 2026-10-30), and a drawn package missing from that plate throws the build. Mass has two sources. @uirouter/core and this repo's own packages are read from www/atlas.lit-ui-router.dev/data/census-bricks.json — scc Code over authored .ts/.tsx/.js/.mjs under each source dir, *.d.ts, specs and typedoc stubs excluded, counted at origin/main @ 08ee3c27 (2026-10-30). The upstream adapters and instruments have no plate at all: their file and line counts are clone counts 2026-08-16 of the ui-router org repositories, carried in this file by hand and labelled as such. 19 packages, 273 authored files, 19,515 lines.

An isometric city would still lie here. Adjacent blocks imply interaction, and the adapters have none — each rib touches only the spine. So the plan stays radial and the new ink is mass: block width ∝ √sloc, block height ∝ file count, which lets a two-file, 233-line package like sticky-states read as the sliver it is beside core's 80-file slab. Core alone is 5,272 lines — 27% of the family's authored mass, and more than the four adapters combined.

The gates disagree, and that is the finding. Every limb declares a range on @uirouter/core, drawn here as a hatched tablet where the limb's stem crosses toward the rail. The dormant instruments still admit core 5 (>=5.0.0, >=5.0.1); rx admits >=6.0.1; angularjs and angular carets on ^6.1.2; this repo's eleven router packages sit on ^6.0.8. One gate is red: @uirouter/react pins core at exactly 6.1.2 and ships it as a dependency, not a peer — the only limb that can install a second copy of the state machine into a consumer's tree, and the only one that cannot be moved forward without a react release.

Mass does not track liveness. The largest limb on the sheet is the dormant @uirouter/visualizer (34 files, 2,018 lines, last published 2020-09-19) — it carries a preact/d3 rendering stack, so it out-masses every living adapter. The limb this repo builds, lit-ui-router, is 25 files and 3,262 lines at 1.19.0, and it is the only limb growing limbs of its own: the companion bay adds another 5,207 lines behind a single shared gate, and 4 of its 10 members peer the limb as well as the spine — lit-ui-router-ssr at ^1.16.1, lit-ui-router-mobx at ^1.16.0, lit-ui-router-effect at ^1.16.0 and lit-ui-router-signals at ^1.16.0. Sheet 2 draws every one of them as a brick but ui-router-registry, which it schedules.

Four companions each stand under a companion they peer. lit-ui-router-ssr declares on lit-ui-router ^1.16.1 and on ui-router-server ^0.6.0, so it cannot be installed without both. That is why it is drawn taking two arrows rather than one — it is a bridge between the element library and the server router, not a limb hanging off either — and it stands under the server in the bay's first column. lit-ui-router-mobx declares on the flagship ^1.16.0 and on ui-router-mobx ^0.2.0, the renderer-free observable store it binds to a Lit host, lit-ui-router-effect declares on the flagship ^1.16.0 and on ui-router-effect ^0.2.0, the renderer-free route ref it binds to a Lit host and lit-ui-router-signals declares on the flagship ^1.16.0 and on ui-router-signals ^0.2.0, the renderer-free signals it binds to a Lit host, so each Lit binding stands under its renderer-free package — the mobx pair in the bay's first column and the effect pair and the signals pair in the bay's second column — its bridge run up that column's right gutter. ui-router-mobx, ui-router-effect and ui-router-signals declare on the spine and on no other limb, as the navigation plugin does. ui-router-registry declares on the spine and, optionally, on ui-router-effect ^0.2.0, ui-router-mobx ^0.2.0 and ui-router-signals ^0.2.0, whose route state its adapter entries type; an install may skip an optional peer, so the bay runs no bridge for them. Every version on this sheet is the one npm serves under latest.

Publish dates sort the family into three states. @uirouter/angular stands at 22.0.0 (2026-08-18), a major of its own, so it is drawn active; angularjs and react carry only the 2025-12-31 patch wave that followed core inside a day, so they are drawn wave. Below the rail nothing is current — the newest instrument publish is rx at 2021-11-30, the rest 2019–2020 — and the dashes say so. @uirouter/vue holds a seat with no registry row at all: an absence, not a package.
