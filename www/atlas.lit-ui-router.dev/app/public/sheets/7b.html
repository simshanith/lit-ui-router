The channels disagree, which is the point. A single wreck-to-splendor axis would have to average these stories away. lit-ui-router is the oldest masonry in the city and its hottest steam and fully lamped — old and running. The typedoc plugin is the only R4 rust on the sheet, cracked flanks and all, yet still emits a puff, because index.ts takes commits while symbols/ sleeps its 234 days. examples steams at 3 puffs with zero lamps and only R1 rust — worked on, untested, barely aging — while docs pairs the city's second-hottest steam with its dimmest metered light (10.7% lit). And @tools/happy-dom keeps plate 7A's strangest fact: a plant with its own spec annex and no lamp lit, because the spec is a canary pointed upstream.

Three channels by import, one by hand. Placements, districts and gate tiers are imported from sheet 7's own placement table, and the masses from www/atlas.lit-ui-router.dev/data/census-city.json, so the two sheets cannot drift building for building. Steam, lamps and pipes are each looked up by member directory in their own filed plate, and a member this sheet draws that a plate does not carry is a build error rather than a stale number. Rust is the exception: an editorial step per member, keyed by badge off sheet 13's weathering census and labelled as such wherever it is printed. The steam total — 307 member-touches from 456 window commits — double-counts commits touching several members, as any per-member count must, so the window commit count is printed beside it.
