Two task managers, one re-entrant loop. The inset at top left is drawn flat, not isometric, because a task manager is not a place — and because the relationship is not the clean layering it sounds like. GitHub Actions enters mise at 37 call sites across 8 workflows (28 distinct tasks); mise itself is almost graphless — 54 tasks with exactly 11 of them declaring depends (15 edges), among them lint_workflows → its four linters and setup → turbo_pin_worktree — because it delegates fan-out rather than modelling it. Seven mise tasks shell turbo, whose ci graph alone expands to 864 task nodes. Then the loop closes back on itself: seven root package.json scripts shell mise run again, so turbo's //#lint:markdown node literally runs mise run lint_markdown. That return is the whole point — mise/aqua owns the versions of the non-node tools (rumdl, taplo, shellcheck, actionlint, zizmor), and turbo climbs back out to it to get a cache key over tools node never installs. Neither gantry is above the other.
