GENERAL NOTES

Method — four provenances, kept apart. This repo's own gates — the core range its four packages share and mobx's range on lit-ui-router — are read from diagrams/data/census-couplings.json (origin/main @ 185d414); the upstream limbs' gates are read from their manifests by hand. Versions and last-publish dates are not typed on this sheet: every one is read by name from diagrams/data/census-npm.json (npm view, npm registry read 2026-09-07), and a drawn package missing from that plate throws the build. Mass has two sources. @uirouter/core and this repo's own packages are read from diagrams/data/census-bricks.json — scc Code over authored .ts/.tsx/.js/.mjs under each source dir, *.d.ts, specs and typedoc stubs excluded, counted at origin/main @ 185d414 (2026-09-07). The upstream adapters and instruments have no plate at all: their file and line counts are clone counts 2026-08-16 of the ui-router org repositories, carried in this file by hand and labelled as such. 12 packages, 209 authored files, 13,851 lines.

An isometric city would still lie here. Adjacent blocks imply interaction, and the adapters have none — each rib touches only the spine. So the plan stays radial and the new ink is mass: block width ∝ √sloc, block height ∝ file count, which lets a two-file, 233-line package like sticky-states read as the sliver it is beside core's 80-file slab. Core alone is 5,272 lines — 38% of the family's authored mass, and more than the four adapters combined.

The gates disagree, and that is the finding. Every limb declares a range on @uirouter/core, drawn here as a hatched tablet where the limb's stem crosses toward the rail. The dormant instruments still admit core 5 (>=5.0.0, >=5.0.1); rx admits >=6.0.1; angularjs and angular carets on ^6.1.2; this repo's four packages sit on ^6.0.8. One gate is red: @uirouter/react pins core at exactly 6.1.2 and ships it as a dependency, not a peer — the only limb that can install a second copy of the state machine into a consumer's tree, and the only one that cannot be moved forward without a react release.

Mass does not track liveness. The largest limb on the sheet is the dormant @uirouter/visualizer (34 files, 2,018 lines, last published 2020-09-19) — it carries a preact/d3 rendering stack, so it out-masses every living adapter. The newest limb, lit-ui-router, is 13 files and 1,383 lines at 1.11.2, and it is the only limb growing limbs of its own: the companion bay adds another 1,422 lines behind a single shared gate, with lit-ui-router-mobx the one package on this sheet that peers a limb as well as the spine.

The family is waking up. The plate makes the movement legible. @uirouter/angular went 22.0.0 on 2026-08-18 — a major, eight months after the 2025-12-31 wave that patched core, angularjs and react inside a day. Read together, the republish wave and the major say the same thing: upstream is consolidating ui-router into a monorepo. That is why @uirouter/angular is drawn active and the other two upstream adapters only wave — they moved because core moved, not on their own. Nothing below the rail has moved: the newest instrument publish is rx at 2021-11-30, and the rest are 2019–2020. And @uirouter/vue stays the one name on the constellation with no registry row at all — an absence, not a package.
