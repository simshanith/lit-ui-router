GENERAL NOTES

At this altitude the reference form breaks. Five, three, and nine modules respectively — an isometric city of four blocks is a worse paragraph. What survives from the reference is its panel: WHAT / HOW / CONDITION, stated on the drawing, including the unflattering parts.

Each companion obeys one verb. ui-router-navigation-location-plugin replaces (the location slot, nothing else). lit-ui-router-mobx observes (core globals in, requestUpdate() out; it never writes router state). ui-router-server re-hosts (the same registry answering requests instead of rendering views). A companion that needed two verbs would be lit-ui-router's problem to absorb, not a package.

The dashed tie is the design claim: client and server share one state registry. What differs is the host — above the line the answer is a rendered <ui-view> tree; below it, a status code.
