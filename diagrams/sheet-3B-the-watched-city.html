GENERAL NOTES

Method — the graph, remeasured. Every mass comes from a fresh bare turbo run ci --dry=json at HEAD (2026-08-31, turbo 2.10.11): 535 nodes, 165 real, 1,375 edges, 117 real→real — against rev B's 501/158/1,294/116 two weeks earlier. Footprint is the per-task inputs map — the files whose hashes decide that task's cache key — at 1.2·√files per side. Height is command mass: the package.json script line plus the repo script or bin file it executes, sloc-counted by census-mass3b.mjs on scc 4.0.0's Code basis (guards, emitters and mise task files each cited in the schedule; external binaries like tsc and oxlint contribute only their one line, because that is all this repo wrote). Wall-clock and cache-hit rates are excluded as geometry by design: they are properties of runs, not of the graph.

The city is flat, and that is still the finding. 130 of 165 real tasks have command mass 1 — one script line handing the work to a pinned binary; the ratio barely moved as the graph grew. The whole city executes 1,774 sloc of repo-written command while watching 27,486 task-file hashes. The skyline is inverted from intuition: @tools/dts-backtest#test is a 291-line run.ts on a 30-file lot — sheet 3 calls it "one 291-line run.ts holds the TS 5.0 floor", and the graph survey agrees to the line — while the largest footprint, the examples plain, watches 17,692 files (format:check 9,129 + lint 8,503 alone) under 23 lines of command. Rev C's one new landmark is in the root yard: //#lint:elements, which rev B drew as "one eslint line" on the shared root surface, now runs the repo's own lint-elements bin — 186 sloc over warn-lanes.core.ts's 214 — so a flat slab became a 401-sloc spire, the tallest command in the city. Nothing about its footprint moved; a lane grew a building.

The root yard repays the walk. All 15 //# plots are drawn individually: five equal slabs — lint:root, typecheck:root, lint:elements, format:check:root, lint:templates — still watch one identical root surface, now 639 files; two one-line flats watch over 1,300 files apiece (lint:package-json 1,383, check:docs-api-deps 1,397); check:patches is a 70-line tower on a 24-file lot. The five-equal-slabs finding is the plate's cleanest, and it survived the refresh exactly — the same five tasks, one surface, one number. The taplo pad (12) is where plate 3A's six-hop chain touches ground: hops ①–② arrive from mise run ci, hop ③ is this block, and ④–⑥ leave immediately to run back inside mise through the cache gasket. And one lot in the yard is vacant on purpose — //#lint:workflows, the virtual with twin, has no command even here.

One tier, uniformly red. Sheet 3's severity vocabulary survives, but at this altitude it degenerates truthfully: every real node in the ci graph stops the PR when it fails, so every massed block wears the same red hatch, and the drawing spends its information elsewhere. The five ci:main-only tasks (test:engines ×3, check:pack, test:matrix) sit outside this survey on an unmassed accent annex; the 370 phantom plots — 69.2% of the graph, transit and ^build hash carriers — are the vacant field behind the city, inventoried hole-by-hole on sheet 12.

Roads and reach. The arteries carry 83 of the 117 real→real edges, and every split came back byte-identical to rev B's: 32 into the docs harbour (every quarter ships docs:api there, plus worker types and app fixtures — docs#build is the city's sink), 20 out of the typedoc plugin (every docs:api waits on it), 15 down to the apps, 12 into the release works (pack:all and check:exports read all four quarters), 4 to the tower. The remaining 34 are local streets. Reach is annotated once, where it is extreme: @tools/typedoc-plugin-lit-ui-router#build:types transitively blocks 57 of the 165 real tasks — the absolute blast radius is unchanged; only the denominator grew.
