Method — the graph, imported. Every mass and footprint on this plate is read from diagrams/data/census-mass3b.json, the checked-in snapshot census-mass3b.mjs writes from a bare turbo run ci --dry=json on an installed archive of the ref — surveyed at origin/main @ eb32b4e (2026-09-04), turbo 2.10.11: 586 nodes, 177 real, 1,382 edges, 96 real→real, against rev C's 535/165/1,375/117. Nothing below is hand-pasted; a structure whose tasks have left the plate throws at build time rather than drawing a stale number, and the schedule totals are the plate's own sums. Footprint is the per-task inputs map — the files whose hashes decide that task's cache key — at 1.2·√files per side. Height is command mass: the package.json script line plus the repo script or bin file it executes, sloc-counted by census-mass3b.mjs on scc 4.0.0's Code basis (guards, emitters and mise task files each cited in the schedule; external binaries like tsc and oxlint contribute only their one line, because that is all this repo wrote). Wall-clock and cache-hit rates are excluded as geometry by design: they are properties of runs, not of the graph.
